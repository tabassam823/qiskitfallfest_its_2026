Panduan Pengembang: Cara Mengaktifkan Login OAuth Nyata

Langkah-langkah integrasi Google OAuth 2.0, GitHub OAuth, dan IBMid

1. Integrasi Google OAuth 2.0 (Google Sign-In)
  1. Buka Google Cloud Console (console.cloud.google.com) dan buat project baru (misal: qiskit-fallfest-its-2026).
  2. Masuk ke APIs & Services > Credentials > Klik Create Credentials > OAuth client ID.
  3. Pilih tipe Web application, lalu tambahkan:
    Authorized JavaScript origins: https://qiskit.its.ac.id, http://localhost:8080
    Authorized redirect URIs: https://qiskit.its.ac.id/api/auth/callback/google
  4. Pasang Google Identity Services script di HTML Anda: 
    <script src="https://accounts.google.com/gsi/client" async defer></script>
<div id="g_id_onload"
     data-client_id="YOUR_GOOGLE_CLIENT_ID.apps.googleusercontent.com"
     data-callback="handleGoogleCredentialResponse">
</div>
2. Integrasi GitHub OAuth (Developer App)
  1. Buka GitHub > Settings > Developer settings > OAuth Apps > New OAuth App.
  2. Isi Homepage URL dan Authorization callback URL (misal: https://qiskit.its.ac.id/api/auth/github/callback).
  3. Arahkan tombol GitHub Sign-In ke endpoint authorization: 
    https://github.com/login/oauth/authorize?client_id=YOUR_GITHUB_CLIENT_ID&scope=user:email
  4. Backend Anda menerima parameter ?code=... lalu menukarnya ke GitHub API untuk mendapatkan profil & email peserta.
3. Integrasi IBMid (IBM Quantum OpenID Connect / OIDC)

IBM Quantum Platform menggunakan IBMid OpenID Connect. Anda dapat mengintegrasikannya menggunakan standard OIDC discovery URL:

• Issuer URL: https://iam.cloud.ibm.com/identity
• Discovery: https://iam.cloud.ibm.com/identity/.well-known/openid-configuration
• Scopes: openid profile email
4. Opsi Paling Cepat & Praktis: Firebase Auth atau Supabase

Jika tidak ingin membuat server backend sendiri dari nol, gunakan Firebase atau Supabase Auth (cukup 5 baris kode JavaScript): 

import { createClient } from '@supabase/supabase-js';
const supabase = createClient('https://xxx.supabase.co', 'PUBLIC_ANON_KEY');

// Login Google / GitHub dalam 1 fungsi:
async function signIn(provider) {
  const { data, error } = await supabase.auth.signInWithOAuth({
    provider: provider // 'google' | 'github'
  });
}
